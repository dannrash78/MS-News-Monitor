# Множествена склероза – актуално | MS News Monitor

**Версия: 1.1.0**

Автоматизиран монитор за надеждни новини и научни публикации за множествена склероза, предназначен като редакционна основа за „Множествена склероза – актуално“.

## Какво има във v1.1.0

- брандиран интерфейс с логото „Множествена склероза – актуално“
- версията е видима директно в името и интерфейса
- конфигурируем списък с източници
- включване/изключване на конкретен източник
- добавяне на нов сайт и RSS/Atom feed
- локално запазване на настройките на източниците
- експорт на текущата конфигурация като `sources.json`
- RSS/Atom ingestion
- дедупликация
- история на обработените публикации
- прозрачно rule-based класифициране и ranking
- TOP кандидати за превод
- GitHub Actions за автоматично изпълнение
- редакционен шаблон за материалите

## Редакционен шаблон

Шаблонът е в `templates/article-template.md` и следва предоставения Word шаблон: заглавие, подзаглавие, дата и тип материал, резюме, защо информацията е важна, основна информация, ключови акценти, източници, авторска бележка и медицинска информационна бележка.

## Управление на източници

От dashboard-а се отваря **⚙️ Източници**.

Важно: браузърът не трябва да получава GitHub token само за да записва `config/sources.json`. Затова UI настройките се пазят локално и могат да се експортират. Следващата стъпка може да бъде защитен административен workflow, който приема експортирания файл и го записва в repository-то.

## Автоматичен мониторинг

GitHub Actions изпълнява монитора ежедневно в 05:00 UTC и може да бъде стартиран ръчно.

Системата е информационен инструмент и не замества медицинска или редакторска проверка.
