# MS News Monitor

Автоматизиран монитор за надеждни новини и научни публикации за множествена склероза.

## V1
- конфигурируем списък с доверени източници
- RSS/Atom ingestion
- дедупликация
- история на обработените публикации
- прозрачно rule-based класифициране и ranking
- TOP кандидати за превод
- GitHub Actions за автоматично изпълнение
- статичен dashboard

## Следващи версии
- AI оценка на медицинска значимост
- извличане на съдържание
- редакционен workflow
- медицински превод
- готов Facebook материал

Системата е информационен инструмент и не замества медицинска или редакторска проверка.
